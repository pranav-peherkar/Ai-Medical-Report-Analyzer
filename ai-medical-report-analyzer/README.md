# AI Medical Report Analyzer

AI-powered healthcare web application using MERN stack, OCR, NLP, and chatbot support.

## Features
- Upload medical reports
- OCR text extraction
- AI-based report analysis
- Abnormality detection
- Chatbot support
- MongoDB storage

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Python Flask
- Tesseract OCR
